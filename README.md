# Agent 开发学习项目

这是一个从 Python 基础逐步学习 Agent 应用开发的练习项目。

## 学习进度

- [第 1 天：Python 基础与 Agent 数据结构](docs/day01/README.md)

## 常用命令

```powershell
cd "D:\Python学习\agent-learning"

# 运行示例
uv run python -m agent_learning.day01_examples

# 运行练习测试
uv run pytest tests/test_day01_exercises.py -v

# 检查代码
uv run ruff check .

# 自动格式化代码
uv run ruff format .
```
